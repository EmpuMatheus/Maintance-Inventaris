# UI_UX.md

# Office Inventory Maintenance System

**Version:** 1.0
**Platform:** Responsive Web Application
**Primary User:** IT Team
**Design Focus:** Fast, Clean, Operational, Mobile-Friendly
**Primary Objective:** Monitoring kondisi dan maintenance inventaris kantor

---

# 1. UI/UX Objectives

Interface harus memungkinkan Tim IT mengetahui kondisi inventaris dengan cepat tanpa harus membuka banyak halaman.

Prinsip utama:

```text
FAST
CLEAN
CLEAR
CONSISTENT
RESPONSIVE
ACTION-ORIENTED
```

User harus dapat melakukan aktivitas utama dengan sedikit langkah.

Contoh:

```text
Scan QR
   ↓
Asset Detail
   ↓
Update Condition
```

atau:

```text
Dashboard
   ↓
Broken Assets
   ↓
Asset Detail
   ↓
Start Maintenance
```

Target UX:

```text
Informasi penting ≤ 3 clicks
```

---

# 2. Design Philosophy

Aplikasi merupakan operational dashboard, bukan website marketing.

Prioritas:

1. Informasi
2. Status
3. Action
4. Navigation
5. Visual

Hindari:

* Animasi berlebihan
* Gradient berlebihan
* Card terlalu banyak
* Modal bertingkat
* Menu terlalu dalam
* Informasi duplikat
* Warna terlalu ramai
* Form terlalu panjang dalam satu layar

# 9. Color System

Gunakan neutral base dengan warna status yang jelas.

Primary:

```text
Blue / Indigo
```

Neutral:

```text
Slate
Gray
White
```

Status semantic:

```text
Green  → Healthy / Completed
Blue   → Information / Active
Yellow → Warning
Orange → Need Attention
Red    → Broken / Critical
Gray   → Inactive / Retired
```

Jangan menggunakan warna sebagai satu-satunya indikator.

Gunakan:

```text
Icon + Text + Color
```
